# v1.5.3 — Feature Completion & Visibility Fixes

## Fixed
- Site logo now appears in the public header and footer.
- Site logo is authorized by the secure image proxy.
- Course page uses the same CloudImage fallback system as cards.
- Logo validation now requires HTTPS image URLs.
- Category chips now actually apply the selected filter.
- Contact / Support is visible on mobile.
- Added floating Support button.
- Direct course-page visits now count as views.
- Click tracking is session-deduplicated and ensures a view is recorded first.
- Historical CTR display is clamped to 100%.
- Multiple featured advertisements can now appear in Featured.
- Support help block on course pages only appears when a support URL exists.
- Admin header uses the configured site name instead of hard-coded VIDORA ADS.
- Added logo preview in General Settings.

## Preserved
- Existing advertisements.
- D1 database.
- Authentication and recovery.
- OpenNext / Cloudflare configuration.
