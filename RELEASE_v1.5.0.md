# v1.5.0 — Course Pages, Support & General Settings

## New public features
- Dedicated page for every published course: `/courses/[slug]`.
- Course detail page includes image, title, category, description, price, discount, schedule, registration CTA and support CTA.
- Course cards now link to the dedicated course page.
- Contact / Support button appears from configurable site settings.

## New Admin feature
- `/admin/settings`
- Configure:
  - Site name
  - Tagline
  - Logo URL
  - Support button label
  - Support URL
  - Support message
  - Footer text

## D1
- New `site_settings` table.
- Self-initializes automatically.
- No destructive migration and no advertisement data changes.
